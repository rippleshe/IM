# 提交材料索引（README）

> 本文件夹只放赛题要求的提交文档。对应关系如下，其余一切以仓库与代码为准。

## 赛题「作品提交形式」 ↔ 本仓库对应物

| 赛题要求 | 对应物 |
|---|---|
| 材料文档：作品设计实现方案 | `作品设计实现方案.md`（唯一主方案，含协同协议/幻觉治理/合规/迁移说明） |
| 材料文档：作品介绍 | `作品介绍.md` |
| 材料文档：演示视频（≤10 分钟） | 按 `演示视频脚本.md` 录制 |
| 软件模块：源代码 | 仓库本身（提交时打包或开放评审权限） |
| 软件模块：部署说明 | `部署说明.md` |
| 软件模块：单元测试用例 | 仓库内 178 用例（`pnpm test`）；清单见 `单元测试说明.md` |
| 测试数据：专业知识库切片 | 仓库内 `data/knowledge/`（616 切片）、`data/datasets/`（AI4I）、MetroPT-3（按部署说明拉取/已在演示机） |
| 测试数据：≥2 组差异化画像数据包 | `data/exports/learner-{foundation,advanced,maintenance}-run-export.json`（三组，均通过 `pnpm verify:export` 八项校验；黄金标注在 `data/evaluation/`） |

## 项目迭代后需要刷新的提交物

| 改了什么 | 刷新什么 |
|---|---|
| 编排/协议/门禁代码 | 跑 `pnpm test`；重新导出三画像数据包（每画像一次运行后从资源/验证页导出） |
| 评测口径或案例集 | `pnpm gold:export` 重新固化黄金标注 → `pnpm evaluate` / `pnpm ablation` 出新报告 |
| 部署相关 | 同步 `部署说明.md` |
| 方案有新创新点 | 只改 `作品设计实现方案.md` 对应章节 |

## 提交前核对（精简版）

1. `pnpm test` / `pnpm typecheck` / 前端构建全绿；
2. 三画像数据包为新代码产物且 `pnpm verify:export` 全过；
3. 评测/消融报告日期与代码版本一致，未宣称未执行的 live 全量结果；
4. 打包不含 `.env`、密钥、数据库文件、node_modules、构建缓存；
5. 视频按脚本录齐四环节，压缩包按"学校—姓名—作品名—电话"命名。
