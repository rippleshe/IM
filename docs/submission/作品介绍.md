# 作品介绍

**IM-Training-Agent** 是一套面向工业设备数据分析与故障诊断技能训练的多智能体协同系统。它回答一个具体问题：大模型怎样在垂直领域既做到"千人千面"的个性化教学，又保证专业内容零漂移、可复核。

## 一句话介绍

以"学情图—声明证据图—协同运行链"为核心的可验证多智能体训练方法：学情决定怎么教，证据约束教什么，运行链记录为何这样决策。

## 核心亮点

1. **可验证的协同，不是流程表演**。六个职责角色、十个执行者（actor）各司其职；每个节点输出结构化、带 SHA-256 散列的不可变产物，上下游通过产物 ID 引用协作。第三方无需调用模型即可离线重算门禁结论（`pnpm replay:run`）。

2. **幻觉治理闭环**。资源草稿被拆成原子事实声明，逐条做确定性核验（数值比对、字段字典核对、越界因果拦截、引用越界检查）；独立批评 Agent 从反方立场质询并发起反证检索；裁决 Agent 与规则门禁取更严格者；修订预算用尽即进入人工复核——**门禁只能收紧，永不放松**。

3. **个性化与事实保真分离验证**。难度、脚手架、路径随学习者画像变化（BKT 状态驱动，预计成功率收敛 65%–80% 教学区间）；字段含义、数据数值、证据边界不随画像漂移。

4. **反馈驱动决策闭环**。作答/反馈后 BKT 前后值、决策（补强/继续/进阶/追问）与理由全部持久化，路径建议直接消费决策记录，下一次运行可引用来源决策，形成"反馈 → 决策 → 下一运行"的链。

5. **数据合规内建**。Cookie 会话隔离、上传资料只存元数据不存正文、导出包自动脱敏、模型隐式思维链永不展示。

## 适用场景

- 高校与高职的"设备数据分析"类实训课程；
- 企业运维/设备工程师转岗培训；
- 任何"有专业证据库 + 需要按学习者状态动态生成资源"的垂直领域（换数据集即换领域）。

## 演示入口

三个预置画像账号（foundation / advanced / maintenance）+ 顶部「验证」页：任意一次协同运行的产物链、声明证据图、裁决记录与离线校验结果均可当场复核。
