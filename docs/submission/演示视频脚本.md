# 演示视频脚本（≤10 分钟）

> 原则：每个时间点证明一个赛题要求；所有画面必须来自真实系统，不使用虚构数据。

| 时间 | 画面 | 演示动作与必须证明的点 |
|---|---|---|
| 0:00–1:00 | 登录 + 画像对比 | foundation 与 advanced 两账号画像/诊断差异；建档向导 + 强制 12 题诊断（逐题作答、服务端判分）→ 证明"差异化输入是真实状态，不是改名字" |
| 1:00–2:20 | 路径页双树对比 | 两棵不同的知识树（起点/深度/分支不同）；节点徽标与"依据"面板（最近决策 + BKT 前后值）→ 证明路径与难度来自学情图 |
| 2:20–4:20 | 学习页发起协同 | foundation 发起讲义任务：群聊逐条冒泡（学情建模→双路并行检索→领域分析→生成），顶部 SSE 节点状态条 → 证明多智能体真实并行与公开产物流动 |
| 4:20–6:20 | 幻觉防控与裁决 | Claim 逐条审核计数；反方质询议题（规则 + 批评 Agent + 反证检索）；裁决双轨取更严；演示一次"未通过 → 修订 → 复审"真实修订环 → 证明幻觉被发现、被拦截、被修订 |
| 6:20–7:20 | 资源页与溯源 | 讲义阅读（代码块 + 数据摘录表可回溯定位）；可信溯源条（门禁状态、难度、来源运行）→ 证明资源可用且可追溯 |
| 7:20–8:20 | 作答反馈与决策闭环 | 习题作答判分 → 路径页节点"依据"更新 → 画像弹窗 before/after → 证明反馈驱动持久化决策 |
| 8:20–9:20 | 验证页 + 离线回放 | 选一次运行：可信摘要、协同链产物散列、声明证据表；点"运行离线复算"看七项校验；终幕 `pnpm replay:run` 命令行输出 → 证明第三方不调用模型可复核 |
| 9:20–10:00 | 收尾 | 三账号路径对比定格 + 一句话架构（PostgreSQL 单数据源 + BullMQ 动态 DAG + VACP 协议；换数据集即换领域）+ 三项指标结果 |

## 录制要点

1. 预置态：`pnpm demo:seed` 后三账号已有路径与诊断；保留一次含修订环的运行历史供 4:20 段演示（不重跑等待）；
2. 4:20 段优先使用已录屏的真实修订环（若现场演示则用截图拼接）；
3. 8:20 段的命令行输出使用 `data/exports/` 中真实导出包；
4. 全程不展示模型思维链；密钥、`.env` 不入镜。
