# Docker 部署指南

本文档提供 IM-Training-Agent 系统的 Docker 部署完整流程。

## 系统要求

- Docker 20.10+
- Docker Compose 2.0+
- 至少 4GB 可用内存
- 至少 10GB 可用磁盘空间

## 环境变量配置

在项目根目录创建 `.env` 文件，包含以下必需配置：

```bash
# 数据库配置
DATABASE_URL=postgresql://postgres:password@db:5432/im_training_agent
POSTGRES_USER=postgres
POSTGRES_PASSWORD=your_secure_password_here
POSTGRES_DB=im_training_agent

# Redis 配置
REDIS_URL=redis://redis:6379

# 阿里云通义千问 API
DASHSCOPE_API_KEY=your_dashscope_api_key_here

# 应用配置
NODE_ENV=production
PORT=3000
SESSION_SECRET=your_random_session_secret_here

# 可选：网络搜索配置（用于证据补充）
TAVILY_API_KEY=your_tavily_api_key_here
```

### 环境变量说明

| 变量名 | 说明 | 是否必需 | 示例值 |
|--------|------|---------|--------|
| `DATABASE_URL` | PostgreSQL 连接字符串 | 必需 | `postgresql://user:pass@host:5432/dbname` |
| `REDIS_URL` | Redis 连接字符串 | 必需 | `redis://host:6379` |
| `DASHSCOPE_API_KEY` | 阿里云通义千问 API Key | 必需 | `sk-xxx` |
| `SESSION_SECRET` | 会话加密密钥 | 必需 | 随机字符串（≥32字符） |
| `TAVILY_API_KEY` | Tavily 搜索 API Key | 可选 | `tvly-xxx` |

## Docker Compose 一键启动

### 1. 克隆仓库

```bash
git clone https://github.com/your-org/IM-Training-Agent.git
cd IM-Training-Agent
```

### 2. 配置环境变量

```bash
cp .env.example .env
# 编辑 .env 填写实际配置
vi .env
```

### 3. 构建并启动服务

```bash
docker-compose up -d
```

服务启动顺序：
1. PostgreSQL 数据库（端口 5432）
2. Redis 缓存（端口 6379）
3. 应用服务（端口 3000）

### 4. 初始化数据库

首次启动需要运行数据库迁移和种子数据：

```bash
# 进入应用容器
docker-compose exec app sh

# 运行数据库迁移
pnpm db:push

# 导入测试数据集（MetroPT-3 + AI4I + 知识卡片）
pnpm seed

# 退出容器
exit
```

### 5. 验证部署

访问 `http://localhost:3000`，应该看到登录页面。

使用测试账号登录：
- 用户名：`learner_001`
- 密码：`password`

## 常见问题排查

### 问题1：端口被占用

**错误信息**：
```
Error starting userland proxy: listen tcp4 0.0.0.0:3000: bind: address already in use
```

**解决方案**：
```bash
# 查找占用端口的进程
lsof -i :3000  # macOS/Linux
netstat -ano | findstr :3000  # Windows

# 修改 docker-compose.yml 中的端口映射
ports:
  - "3001:3000"  # 改用 3001 端口
```

### 问题2：pgvector 扩展未安装

**错误信息**：
```
ERROR: extension "vector" is not available
```

**解决方案**：
```bash
# 进入数据库容器
docker-compose exec db psql -U postgres -d im_training_agent

# 手动安装 pgvector 扩展
CREATE EXTENSION IF NOT EXISTS vector;

# 退出
\q
```

### 问题3：内存不足

**错误信息**：
```
Killed
或应用无响应
```

**解决方案**：

编辑 `docker-compose.yml`，增加内存限制：

```yaml
services:
  app:
    deploy:
      resources:
        limits:
          memory: 2G  # 增加到 2GB
```

### 问题4：数据库连接失败

**错误信息**：
```
Error: connect ECONNREFUSED 127.0.0.1:5432
```

**解决方案**：
```bash
# 检查数据库容器状态
docker-compose ps db

# 检查数据库日志
docker-compose logs db

# 确保 DATABASE_URL 使用服务名 'db' 而不是 'localhost'
DATABASE_URL=postgresql://postgres:password@db:5432/im_training_agent
```

## 生产环境优化建议

### 1. 使用外部数据库

生产环境建议使用托管数据库服务（如 AWS RDS、阿里云 RDS）：

```bash
# .env 配置
DATABASE_URL=postgresql://user:pass@rds.example.com:5432/prod_db

# docker-compose.yml 注释掉 db 服务
# services:
#   db:
#     ...
```

### 2. 启用持久化卷

确保数据不会因容器重启而丢失：

```yaml
services:
  db:
    volumes:
      - ./data/postgres:/var/lib/postgresql/data
  
  redis:
    volumes:
      - ./data/redis:/data
```

### 3. 配置反向代理

使用 Nginx 作为反向代理：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }
}
```

### 4. 启用日志轮转

防止日志文件无限增长：

```yaml
services:
  app:
    logging:
      driver: "json-file"
      options:
        max-size: "10m"
        max-file: "3"
```

## 监控与维护

### 查看资源使用情况

```bash
docker stats
```

### 数据库备份

```bash
# 备份数据库
docker-compose exec -T db pg_dump -U postgres im_training_agent > backup_$(date +%Y%m%d).sql

# 恢复数据库
docker-compose exec -T db psql -U postgres im_training_agent < backup_20250101.sql
```

### 清理未使用的资源

```bash
# 清理悬空镜像
docker image prune -f

# 清理未使用的容器
docker container prune -f

# 清理未使用的卷
docker volume prune -f
```

## 安全建议

1. **不要在生产环境使用默认密码**
2. **定期更新 SESSION_SECRET**
3. **使用 HTTPS（配合 Let's Encrypt）**
4. **限制数据库端口仅内部访问**
5. **启用防火墙规则**
6. **定期备份数据库**
