# 部署与故障排查说明

> 分两种环境：**A. 已有完整数据环境**（演示机，数据与嵌入已就位）与 **B. 需要下载数据的干净环境**。演示机使用 A 路径，不重新下载。

## A. 已有完整数据环境（推荐演示路径）

```bash
# 1. 启动基础设施（本机端口映射见 .env：POSTGRES_PORT/REDIS_PORT）
docker compose up -d postgres redis

# 可选：本地网络补全检索（不影响 PostgreSQL/Redis 主线）
# 在 .env 设置 SEARXNG_ENABLED=true 后重启 api 与 worker
docker compose --profile search up -d searxng

# 2. 应用 schema 迁移（00 00~0010 已随仓库提交）
pnpm db:migrate

# 3. 启动三件套
pnpm server        # api :3001
pnpm worker        # BullMQ DAG 执行器
pnpm --dir web dev # 前端 :3000

# 4. 演示账号（幂等；密码从 .env 注入）
pnpm demo:seed
```

登录任一演示账号即可演示完整闭环；已有运行历史可直接在「验证」页复核。

## B. 需要下载数据的干净环境

```bash
pnpm install                     # 安装依赖（Node 18+，pnpm）
cp .env.example .env             # 配置 DASHSCOPE_API_KEY / DATABASE_URL / REDIS_URL
docker compose up -d postgres redis
pnpm db:migrate
pnpm db:bootstrap                # 幂等引导：迁移→Metro 目录→AI4I→知识卡
pnpm data:metropt                # 可选：UCI 官方下载 MetroPT-3（约 208MB，SHA256 校验）后自动导入
pnpm docs:embed                  # 可选：向量回填（按内容哈希缓存，避免重复计费）
pnpm demo:seed
```

无 MetroPT-3 完整 CSV 时系统仍可运行（AI4I + 知识卡路径），界面如实展示数据准备状态，**不生成伪时序数据**。

## 常用验证命令

| 命令 | 用途 |
|---|---|
| `pnpm test` / `pnpm typecheck` | 191 用例 + 类型检查 |
| `pnpm evaluate` | 60 案例离线评测（`--live --stride N` 需授权） |
| `pnpm ablation` | 三组消融实验 |
| `pnpm verify:export <file>` | 导出包完整性校验（离线） |

| `pnpm gold:export` | 重新导出黄金标注（案例定义变更后） |

## 故障排查

| 现象 | 原因与处理 |
|---|---|
| api 启动后模型调用失败 | `.env` 缺 `DASHSCOPE_API_KEY`，或未配置模型服务——默认模型与 provider 见 `.im-training-agent/model-settings.json`（当前默认 OpenCode Zen `mimo-v2.5-free`，可在设置页或该文件切换为 DashScope `qwen-plus`）；`dotenv` 时序问题——`study-runtime`/`study-context` 顶部已前置 `import 'dotenv/config'`，勿改动 import 顺序 |
| 5432/6379 被本机原生服务占用 | 本机映射为 `15432/16379`（见 `.env` 的 POSTGRES_PORT/REDIS_PORT），容器内仍是标准端口 |
| 运行一直 running | worker 未启动或旧 worker 未重启（tsx 无热重载，改代码必须重启 worker）；`pnpm worker` 后看 `worker.log` |
| 事件流断开后不续传 | SSE 以 `run_events.seq` 单调续传，检查是否直连 3001（代理需关闭缓冲，`X-Accel-Buffering: no` 已内建） |
| 迁移报错 | 迁移文件全部幂等（IF NOT EXISTS / ADD COLUMN IF NOT EXISTS）；确认 `DATABASE_URL` 指向容器库而非本机原生 PG |
| 前端构建拉取 Google Fonts 失败 | 仓库已改为系统字体栈，离线可构建；若被改动请回退 `web` 内字体引用 |
| live 评测未运行 | 评测默认离线；`--live` 需 `IM_TRAINING_AGENT_DEMO_PASSWORD` 与 api+worker 在跑，且须经调用量授权 |
| 镜像构建失败（docker.io 不可达） | 演示不需要镜像构建；api/worker 本机 tsx 运行，postgres/redis 用官方镜像即可 |
| 网络补全未生效 | 默认关闭；执行 `docker compose --profile search up -d searxng`，在 `.env` 设 `SEARXNG_ENABLED=true`，再重启 api 与 worker。若返回 403，检查 `deploy/searxng/settings.yml` 是否保留 `search.formats: [html, json]` |

## 数据安全

- `.env` 不入 Git；演示密码、密钥不写进任何文档与日志；
- 提交包检查见包根目录《提交说明.md》。
