# 《智辩无幻》测试数据说明

测试数据覆盖“差异化画像输入 → 多智能体协同 → 个性化资源输出”的完整评测链路，仅含公开许可资料与脱敏样例。

| 目录 | 内容 | 用途 |
| --- | --- | --- |
| `数据集/ai4i/` | AI4I 2020 Predictive Maintenance Dataset 的本地测试副本 | 设备故障标签、字段与统计训练 |
| `知识库切片/` | 13 张工业设备诊断与数据分析知识卡 | 证据定位与教学解释 |
| `差异化画像数据包/personas.json` | 零基础制造现场、进阶数据分析、在职运维转岗三类初始画像 | 难度、脚手架与路径分化 |
| `差异化画像数据包/*-run-export.json` | 三组真实运行导出，含输入画像、中间协同轨迹、证据包、生成资源和最终状态 | 完整输入—输出样例 |
| `差异化画像数据包/gold-*.json` | 60 个固定金标评测案例及知识点标注 | 难度适配与知识覆盖评测 |

## 复现方式

在项目根目录完成部署后运行：

```bash
pnpm verify:export
pnpm replay:run
pnpm evaluate
pnpm ablation
```

前三项分别校验导出完整性、重放三组真实运行和执行 60 个离线金标案例；最后一项比较动态画像规划与固定计划。详细口径与结果见 `../01-作品文档/评测方案与结果报告.md`。
