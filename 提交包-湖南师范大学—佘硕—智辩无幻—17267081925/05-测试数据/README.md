# 《智辩无幻》测试数据说明

本目录用于复现“差异化画像输入 → 多智能体协同 → 个性化资源输出”的完整评测链路；不含账号凭据、会话 Cookie、真实用户数据或模型密钥。

| 目录 | 内容 | 对应赛题要求 |
| --- | --- | --- |
| `数据集/ai4i/` | AI4I 2020 Predictive Maintenance Dataset 的本地测试副本 | 一个垂直专业领域的数据基础 |
| `知识库切片/` | 29 份机械设备诊断、数据处理与证据边界的 Markdown 知识切片 | 一个垂直专业领域知识库切片 |
| `差异化画像数据包/personas.json` | 三类初始学习者画像：零基础制造现场、进阶数据分析、在职运维转岗 | 不少于两组差异化初始画像来源 |
| `差异化画像数据包/*-run-export.json` | 三组真实运行导出，含输入画像、中间协同轨迹、证据包、生成资源和最终状态 | 完整输入—输出示例 |
| `差异化画像数据包/gold-*.json` | 60 个固定金标评测案例及知识点标注 | 个性化与知识准确性评测基准 |

## 复现方式

在项目根目录完成部署后运行：

```bash
pnpm verify:export
pnpm replay:run
pnpm evaluate
pnpm ablation
```

前三项分别校验导出完整性、重放三组真实运行和执行 60 个离线金标案例；最后一项比较动态画像规划与固定计划。详细口径、结果与限制见 `../01-作品文档/评测方案与结果报告.md`；每组真实运行的固定队列与证据字段说明见 `差异化画像数据包/固定真实运行队列说明.md`。
