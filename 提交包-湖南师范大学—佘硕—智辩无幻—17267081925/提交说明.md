## 二、提交前只需完成的两件事

1. 将最终答辩 PPT 放入 `02-答辩PPT/`，将不超过 10 分钟的演示视频放入 `03-演示视频/`。视频应展示：差异化画像输入 → 多智能体协同过程可视化 → 个性化资源生成 → 反馈后的下一步决策。
2. 在源码目录执行下列命令，并确认均通过：

```bash
pnpm test
pnpm typecheck
pnpm --dir web build
pnpm evaluate
pnpm ablation
```

如需再次检查三组真实运行数据，依次执行：

```bash
pnpm verify:export ../05-测试数据/差异化画像数据包/learner-foundation-run-export.json
pnpm replay:run ../05-测试数据/差异化画像数据包/learner-foundation-run-export.json
```

## 三、打包边界

本包不包含 `.env`、模型密钥、Cookie、运行缓存、构建产物、`node_modules`、本地数据库或用户上传正文。源码压缩包中的 `.env.example` 仅提供变量名与安全示例；实际密钥由部署者自行配置。

赛题要求以邮件统一压缩提交；如压缩包过大，可按赛题要求上传安全云盘，并将链接、提取码和包含上传时间的截图发送至指定邮箱。
