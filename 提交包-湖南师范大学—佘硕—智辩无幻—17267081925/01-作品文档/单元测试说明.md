# 单元测试说明

> 赛题要求提交"针对多智能体协同调度逻辑与领域知识生成准确性等核心模块"的单元测试用例。
> 测试用例本身在仓库内（与代码同源、随提交走），本文档说明覆盖范围与运行方式。

## 运行方式

```bash
pnpm test        # 全量 203 用例（vitest，离线运行，不访问外网、不调用模型）
pnpm typecheck   # TypeScript 全量类型检查
```

## 补充验证（脚本，非 vitest）

- `pnpm evaluate`：60 案例离线评测（三画像 × 20，阈值不达标退出码 1）；
- `pnpm ablation`：三组消融实验（动态 DAG 分化 / 门禁净增益 / 难度校准）；
- `pnpm verify:export <file>` / `pnpm replay:run <file>`：对提交数据包做离线完整性与回放校验。
