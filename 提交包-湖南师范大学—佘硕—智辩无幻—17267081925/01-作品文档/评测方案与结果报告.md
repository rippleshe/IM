# 《智辩无幻》评测方案与结果报告

> **复核日期：2026-09-03**
> 离线规则评测验证难度适配与知识覆盖；真实模型运行队列验证检索、生成、审核、返修与发布门禁。

## 1. 评测目标与证据链

赛题对实用价值提出三项核心目标：专业知识谬误率（幻觉率）<5%、画像—资源难度适配准确率≥85%、核心知识点覆盖率≥90%。评测采用两类互补证据：

| 评测层 | 解决的问题 | 数据与命令 | 防止的误读 |
|---|---|---|---|
| 60 案例离线规则评测 | 难度校准和知识库覆盖是否满足阈值 | `pnpm evaluate` | 规则指标与模型生成结果分开统计 |
| 三组固定真实运行队列 | 多智能体门禁是否真的拦截并修订无依据内容 | `pnpm ablation`、`pnpm verify:export`、`pnpm replay:run` | 不用“最终成品看起来正确”替代过程审计 |
| 204 项自动化测试 | 协同协议、核验规则、决策与资源契约是否回归 | `pnpm test` | 覆盖协同内核与资源契约回归 |

## 2. 测试数据设计

### 2.1 垂直领域专业知识库

`05-测试数据/` 提供工业设备数据分析与故障诊断领域的可提交最小知识库：

- **AI4I 2020 数据集**：`数据集/ai4i/ai4i_2020.csv`，用于设备故障标签、字段分析、统计与 Python 实训；
- **MetroPT-3 知识切片**：`知识库切片/dataset-metropt3.md`，说明空压机时序数据字段、采样与使用边界；
- **领域知识切片**：AI4I 故障模式、时间序列、数据清洗、异常阈值与 pandas 操作等 Markdown，均可定位到来源主题；
- **不纳入提交的内容**：运行缓存、模型密钥、Cookie、上传原文、构建产物和本地数据库均不放入数据包。

### 2.2 三组差异化画像完整输入输出

`差异化画像数据包/` 包含三组不同背景学习者的画像、初始技能状态、运行计划、协同中间产物、Claim—Evidence 链、裁决、终稿资源和运行结束状态：

| 画像 | 训练定位 | 导出文件 | 真实运行特点 |
|---|---|---|---|
| 零基础学习者 | 建立数据阅读与证据边界 | `learner-foundation-run-export.json` | 低难度脚手架、两轮门禁修订 |
| 进阶学习者 | 统计/分析能力进阶 | `learner-advanced-run-export.json` | 更高难度目标、两轮门禁修订 |
| 在职转岗学习者 | 诊断表达与现场决策 | `learner-maintenance-run-export.json` | 兼顾现场经验与数据边界、三轮门禁修订 |

导出包保留运行 ID、协同产物、证据链、裁决与终稿资源，仅含公开资料和脱敏样例。

## 3. 指标与判定口径

| 指标 | 正式口径 | 达标线 | 不计入项 |
|---|---|---:|---|
| 幻觉率 | `unsupported` 事实 Claim / 全部可审计事实 Claim | <5% | 非事实教学表达、空分母（记 N/A） |
| 难度适配准确率 | 难度落在目标区间且符合脚手架与画像的案例 / 全部案例 | ≥85% | 不用固定难度替代画像校准 |
| 核心知识覆盖率 | 有有效证据边支持的必备知识点 / 黄金必备知识点 | ≥90% | 不以关键词偶然出现代替 live Claim—Evidence 覆盖 |

**发布规则**：任何无依据 Claim、数值/字段语义冲突、越界因果、引用不可定位或隐私门禁失败，都会使资源不发布。裁决结论只能与规则结论一样严格或更严格。

## 4. 已复现结果

### 4.1 60 案例离线评测

执行 `pnpm evaluate`，结果如下：

| 项目 | 结果 | 判定 |
|---|---:|---|
| 案例数 | 60（3 画像 × 20） | 通过 |
| 难度适配准确率 | 100%（60/60） | ≥85%，通过 |
| 核心知识覆盖率 | 100% | ≥90%，通过 |
| 幻觉率 | N/A | 离线模式不调用模型，按口径不伪报为 0 |

案例覆盖 AI4I 与 MetroPT-3、基础/进阶/迁移任务、讲义/PPT/分层习题/知识脉络四类正式资源。黄金案例、画像先验与知识点映射分别位于 `差异化画像数据包/gold-cases.json`、`personas.json` 和 `gold-knowledge-points.json`，与源码评测输入散列一致。

### 4.2 三组固定真实运行队列

执行 `pnpm ablation`，并对三份提交导出包逐一执行 `pnpm verify:export` 与 `pnpm replay:run`：

| 画像 | 初稿可审计 Claim | 初稿无依据 | 终稿无依据 | 返修 | Claim—Evidence 引用 | 导出/回放 |
|---|---:|---:|---:|---:|---:|---|
| 零基础 | 8 | 1（12.5%） | 0（0%） | 2 轮 | 35 | 通过 |
| 进阶 | 8 | 3（37.5%） | 0（0%） | 2 轮 | 32 | 通过 |
| 在职转岗 | 8 | 2（25.0%） | 0（0%） | 3 轮 | 43 | 通过 |

按三组 Claim 数量加权，门禁消融结果为：

- 初稿幻觉率 **25.0%**；
- 终稿幻觉率 **0%**；
- 门禁净增益 **25 个百分点**；
- 三组真实运行均触发修订，且均通过散列、DAG 依赖、事件序号、输入引用、裁决不放松、fail-closed 发布与敏感信息检查。

### 4.3 个性化消融对照

## 6. 第三方复现步骤

```bash
# 1. 在源码目录安装依赖、配置 .env 并启动 PostgreSQL / Redis
pnpm install
docker compose up -d postgres redis
pnpm db:migrate
pnpm db:bootstrap

# 2. 运行离线测试与评测
pnpm test
pnpm typecheck
pnpm --dir web build
pnpm evaluate

# 3. 对三组真实运行记录做独立核验
pnpm verify:export ../05-测试数据/差异化画像数据包/learner-foundation-run-export.json
pnpm replay:run ../05-测试数据/差异化画像数据包/learner-foundation-run-export.json
pnpm ablation
```

## 7. 真实模型评测范围

真实模型评测采用三组固定运行队列，分别覆盖零基础、进阶和在职转岗画像；每组均保留初稿、返修、终稿、Claim—Evidence 链、裁决和发布结果，并可离线重放。60 案例评测用于验证确定性的难度适配与知识覆盖口径。获得调用授权后，可通过 `pnpm evaluate --live --stride N` 执行分层 live 评测，报告会自动标注实际样本数与口径。
