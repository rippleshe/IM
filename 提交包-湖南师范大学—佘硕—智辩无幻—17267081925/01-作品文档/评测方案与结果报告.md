## 1. 评测方案

### 1.1 案例集

- **60 个固定案例**（`data/evaluation/gold-cases.json`，由 `src/learning/evaluation.ts` 确定性生成）：三画像（foundation / advanced / maintenance）各 20，覆盖 AI4I 与 MetroPT-3 两个数据集、当前已交付的四类资源（讲义、PPT、分层习题、知识脉络）及基础/进阶/迁移三层任务。实操指南与挑战任务已纳入任务语义，但尚未作为独立资源类型计入本轮统计。
- 三组差异化画像先验：`data/evaluation/personas.json`（与 `pnpm demo:seed` 的诊断作答模式一致）。
- 黄金知识点 → 检索关键词映射：`data/evaluation/gold-knowledge-points.json`。

### 1.2 三项官方指标口径（固定，见 `server/runs/metrics.ts`）

| 指标 | 口径 | 阈值 |
|---|---|---|
| 幻觉率 | unsupported 事实 Claim / 全部可审计事实 Claim；`non_factual` 不入分母；空分母报 N/A | < 5% |
| 难度适配准确率 | 目标区间 ∩ 脚手架 ∩ 画像全匹配案例 / 全部案例（预测与实际作答分开报告） | ≥ 85% |
| 核心知识覆盖率 | 有有效 evidence edge 支持的必备知识点 / 黄金必备知识点（live 按声明证据边判定，非关键词命中） | ≥ 90% |

### 1.3 结果分层（诚实口径）

报告区分四层：**离线规则结果**（`pnpm evaluate` 默认）、**固定真实运行队列**（三画像导出包，含散列与离线回放）、**本次 live 结果**（`--live`，需用户授权后运行）、**离线回放核验**。未跑全量 live 时如实标注 `stratified_live_N + offline_full_60`，不笼统称全量实测。

## 2. 当前结果

### 2.1 离线规则结果（`pnpm evaluate`，60 案例全量）

- 难度适配准确率 **100%**（60/60，预测口径）
- 核心知识覆盖率 **100%**（黄金知识点全部有知识库支撑）
- 幻觉率：离线模式不调用模型，**N/A**（需要 live 运行产生声明数据；不以 0 冒充）
- 阈值校验通过；报告：`data/evaluation-report-*.json`

### 2.2 固定真实运行队列（消融实验 `pnpm ablation`）

| 组 | 结论 | 结果 |
|---|---|---|
| A1 动态 DAG vs 固定 DAG | 三画像计划真实分化 | 动态 **3 种计划**（固定仅 1 种）✔ |
| A2 门禁消融（初稿 vs 终稿，按轮次口径） | 门禁对已发布运行的净增益 | 固定三画像队列：初稿幻觉率 **25.0%**，终稿 unsupported 事实声明 **0**；3 次均触发修订 ✔ |
| A3 BKT 难度校准 vs 固定难度 0.42 | 校准预计成功率入 65–80% 教学区间 | **33/33**（固定难度仅 2/33）✔ |

- 三个运行分别对应零基础、进阶、在职转岗学习者；固定清单位于 `data/evaluation/live-run-cohort.json`，逐份锁定 SHA-256、运行标识与导出包。命令会先验证散列，再复算每轮门禁；任一文件被替换、篡改或回放不一致都会失败。三画像导出包均通过完整性校验。

### 2.3 离线复核能力（第三方可复现）

- 导出包完整性七项校验（产物散列、DAG 闭合、事件 seq、inputRefs、Claim—Evidence、裁决只紧不松、发布 fail-closed、敏感字段）全部有单元测试；
- 注入式验收已验证：篡改产物 → 散列校验发现；删除证据边 → 完整性发现；放松裁决 → 回放发现（`server/runs/metrics.test.ts` 13 用例）。

### 2.4 live 评测状态（如实说明）

- 已有历史分层 live 评测（9 个分层案例，`data/` 下历史报告）验证真实生成链路；
- 60 案例全量 live 需要模型调用量授权，执行方式：`pnpm evaluate --live --stride N`（分层），报告自动区分口径。**当前提交不宣称未执行的 live 全量结果。**

## 3. 离线回放核验方案

12 个分层样本 + 全部失败案例执行离线回放核验；每个样本回答：是否存在事实错误 / 证据是否真正支持 / 引用能否定位 / 难度是否适合画像 / 必备知识点是否讲到 / 行业边界是否清楚 / 下一步动作是否合理。核验记录随演示包归档，不要求学习者参与审核。
